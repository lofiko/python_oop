# ЛР-4 — Интерфейсы и абстрактные классы (Python 3.x)

## Цель работы

Познакомиться с абстрактными базовыми классами (ABC), освоить понятие интерфейса как контракта поведения, научиться задавать обязательные методы для классов и закрепить полиморфизм через единый интерфейс.

---

## Описание интерфейсов

**`Printable`** — интерфейс для вывода информации об объекте. Требует реализации метода `to_string()`.

**`Comparable`** — интерфейс для сравнения объектов. Требует реализации метода `compare_to(other)`.

---

## Реализация в классах

Все три класса — `PrintedBook`, `Ebook`, `AudioBook` — реализуют оба интерфейса через базовый класс `Book(Printable, Comparable)`.

`to_string()` работает по разному в каждом классе:
- `PrintedBook` — добавляет издательство и переплёт
- `Ebook` — добавляет формат и размер файла
- `AudioBook` — добавляет длительность и чтеца

`compare_to(other)` — сравнивает две книги по цене, возвращает разницу.
